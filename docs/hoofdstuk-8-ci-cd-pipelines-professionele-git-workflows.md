# CI/CD pipelines & professionele Git workflows

## Leerdoelen

- CI/CD-principes toepassen op een webproject.
- Branchingstrategieën en pull request workflows professioneel inzetten.
- Automatische kwaliteitscontroles in pipelines integreren.

## Kerninhoud

Je bekijkt hoe teams codekwaliteit en deploymentbetrouwbaarheid verhogen via geautomatiseerde tests, linting, buildstappen en reviewprocessen.

## Oefenopdracht

Ontwerp een basispipeline die test, lint en build uitvoert bij elke pull request.
