# Docker fundamentals: introductie tot containers

## Leerdoelen

- Containers onderscheiden van virtuele machines.
- De Docker-architectuur (engine, daemon, registry) beschrijven.
- Eenvoudige containercommando's correct gebruiken.

## Kerninhoud

Je verkent waarom containers lichtgewicht en reproduceerbaar zijn. Daarnaast leer je images ophalen, containers starten en logs, poorten en volumes beheren.

## Oefenopdracht

Start een webservercontainer, publiceer de juiste poort en toon aan dat de service lokaal bereikbaar is.
