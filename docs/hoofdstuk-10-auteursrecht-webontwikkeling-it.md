# Auteursrecht binnen webontwikkeling en IT

## Leerdoelen

- De basisprincipes van auteursrecht in softwarecontext uitleggen.
- Licenties en hergebruik van code correct beoordelen.
- Risico's rond inbreuk in teamprocessen verminderen.

## Kerninhoud

Je behandelt eigendom van code, open source licenties, gebruiksvoorwaarden van assets en praktische richtlijnen voor compliant softwareontwikkeling.

## Oefenopdracht

Maak een licentiechecklist voor een project met externe libraries en digitale assets.
