# HTTP

## Leerdoelen

- Request/response-communicatie van HTTP interpreteren.
- Statuscodes, methoden en headers functioneel gebruiken.
- Caching en content negotiation in webapplicaties toepassen.

## Kerninhoud

Je onderzoekt de structuur van HTTP-berichten, de semantiek van GET/POST/PUT/DELETE en het belang van headers voor caching, authenticatie en API-ontwerp.

## Oefenopdracht

Analyseer met browser devtools een complete requestflow en verklaar de belangrijkste headers en statuscodes.
